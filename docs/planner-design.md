# 复习计划页设计记录

记录日期：2026-11-04。页面模式：Operate。范围：沿用已确认的内部黑白橙系统，扩展现有复习计划页。

全局视觉权威仍是 [DESIGN.md](../DESIGN.md) 与 [.impeccable/design.json](../.impeccable/design.json)，本文不新增全局 tokens。功能与排期约定见 [planner-spec.md](planner-spec.md)。本文记录当前实现，不代表独立审查通过。

## Overview

页面把当天任务、可用时间和考前缺口放在一起。首次默认时间线，也可切换按天完成；两者共用任务与完成状态。规划条件在当前页展开，安排依据、算法说明、科目字段和专注计时按需展开。

对照课程页的共享外壳，计划页保留黑色侧栏、灰白画布、顶部路径与搜索、橙色导航标记、系统中文字体和白色轻边框表面；新增的日程和助手构成属于本页扩展。现存 `plan-desktop.png` 已是新页面，不作为旧计划页的 before 证据。

## Colors

画布、表面、正文、主操作与基础边界继承全局定义。局部 `--sp-border`、`--sp-orange` 对应既有边界和橙色；页面另有暖灰次文字值，不改变全局次文字 token。

选中日期与助手说明区使用近黑色实底，橙色用于进度及操作强调。浅暖色提示时间不足、未排入分钟或校验失败；完成反馈结合浅绿表面、勾选、文字和划线。

橙、蓝、灰、褐四组低饱和色点和浅色任务卡仅辅助识别课程。颜色按课程顺序循环，超过四门会复用，不表示成绩、难度或永久的学科身份；课程名称与类型始终保留。

## Typography

继承全局字体栈与16px正文基准，页面标题桌面34px、手机28px。当天标题桌面21px、手机18px；任务标题桌面17px、手机16px。学习入口、完成文字与安排依据以14px为主，时间使用等宽数字。

当前仍有11–13px的日期附注、预算元信息、单位、部分表单说明及侧栏附注；这些局部紧凑层级不应扩展为全局辅助字号。长课程名与任务标题允许折行。

## Layout

首屏依次为标题、双模式与调整入口、周日期、当天安排。设置在工具栏下内联展开。日程内部依次为月份与翻周、七天日期、当天标题、分钟及进度、当天提示、任务和重算入口。

桌面日程与295px助手并列，间距26px；1320px以下助手缩为265px。1120px以下改为日程在上、助手在下，助手内部暂为两列；760px以下助手单列。手机在日程前额外显示时间缺口和缺少考试日期的摘要。

手机沿用20px内容边距与底部导航。模式切换和44px调整图标同排，更新状态保留为读屏状态。日期选择器隐藏，仍可用今天、翻周与七天按钮浏览。日期条实际为七列等分网格，没有横向滚动。

设置区的目标桌面三列、手机单列；每周分钟桌面七列、手机四列；科目字段桌面三列、手机两列、360px以下单列。原生折叠区避免同时铺开全部科目字段。

## Elevation & Depth

层次主要来自画布、白色表面、细边框与深色助手区。日程和任务卡没有大面积投影；分段选中项只有轻微阴影，主要按钮沿用共享悬停反馈。共享状态过渡160ms，设置进入180ms，进度宽度更新260ms；减少动态偏好关闭本页动画与过渡。

## Shapes

日程和设置桌面圆角16px，任务卡12px，助手14px；手机日程和设置13px、时间线卡10px。按钮与输入继承共享控件语言。时间线由细竖线、小圆节点与独立休息行组成。

完成方框的实际命中区为44×44px。翻周、折叠等辅助控件仍有更小尺寸，不能宣称全页控件均达到44px。

## Components

| 组件 | 实际交互与边界 |
| --- | --- |
| 双模式 | 时间线安排专注段与休息；按天模式只约定任务，不固定顺序。切换保存偏好，失败恢复原模式并提示。 |
| 日期与预览 | 周日期、今天和翻周切换日期；未来日期可查看和开始学习，标为预览，完成按钮等到当天开放。 |
| 任务完成 | 两种视图共用任务标识；分段任务只有第一段提供整项完成入口并说明总分钟，后续段收紧为延续信息。完成可撤销；完成后开始学习禁用。保留原始完成分钟，重排未完成工作。 |
| 当天进度 | 区分完成分钟、安排分钟、可用分钟、任务数和缓冲；时间线额外显示休息。未排入分钟独立提示并可调整时段。日预算不等于时间线容量。 |
| 目标与时间 | 及格优先、兼顾提分、高绩点；每周预算、起点、空闲时段、25/40/50分钟专注、5/10分钟休息和0–25%缓冲。 |
| 科目设置 | 考试日期与展示用考试时间、难度、目标、掌握估计、剩余小时和单科起点。剩余小时留空才估算，明确标识；考试当天统一预留，不按考试时刻插入该科新任务。 |
| 单日调整 | 指定日期的分钟及空闲时段独立应用，可设休息日、恢复常规。常规条件通过“保存并重新规划”提交，编辑字段不立即重排；收起后重开读取已保存值。 |
| 校验与焦点 | 时段结束晚于开始、互不重叠、最多五个；数值字段有范围。保存错误保留设置并提示，关闭后焦点回到调整入口。 |
| 规划助手 | 显示当前策略、逐科日期与准备状态、估算或手填工作量及模式对应的缺口；调整入口打开相应设置。 |
| 专注计时 | 沿用已有25分钟计时、暂停/继续/重置和真实累计分钟；折叠于助手区，不自动对应每个排期段，也不自动完成任务。 |

安排在日期或应用数据变化、成功操作后刷新；页面可见时每60秒检查，窗口重新获得焦点也刷新。请求序号阻止旧日期响应覆盖新日期。“随学习进度更新”指这些机制，不表示连续推送。

模式与日期使用原生按钮及 `aria-pressed`；设置标签页支持左右方向键、Home和End。字段、折叠区及操作可用键盘访问，保留可见焦点。进度条、更新状态和错误具有对应读屏语义。

首次读取显示加载，已有结果刷新时保留内容；读取失败可重新加载。无课程提供添加入口；零预算说明休息日；无任务引导检查条件；未设日期、未到准备起点、考试已到或已结束、容量不足分别说明。全部任务完成后提供完成反馈。

排期是可解释的本地滚动建议，无需模型密钥；估算不代表成绩预测，不宣称最优。记忆卡继续由FSRS独立调度。旧完成记录迁移与持久化属于服务端职责。

## Do's and Don'ts

- Do 保留共享视觉，在页面内扩展日程和助手；区分预算、时段、缓冲、休息及未排入分钟。
- Do 明说估算、整项完成、未来预览和考试日预留，并在手机日程前暴露关键缺口。
- Don't 把课程识别色升级为全局品牌色、难度或成绩含义。
- Don't 用重排覆盖原始完成分钟，或把单个专注段完成视为整项完成。
- Don't 把页面记录、截图或测试输出写成独立审查通过结论。
