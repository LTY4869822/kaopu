# 考谱内部 UI 改版实施规格

用户已认可 ui-reference-shortlist.md 的设计方向。此轮是结合参考的原创实现，不是逐像素复制第三方设计稿。

## 统一基础
- 以 Ronas 课程视觉、SkillLabs 目录组织、Skillsphere 分栏阅读为参考。
- 画布 #f5f5f3；表面 #ffffff；正文 #191919；次文字 #6c6c70；边界 #e5e5e1；橙 #fa5b35；浅橙 #fff0e9。
- 黑色侧栏 #191919，宽224px，橙色品牌；阅读主体浅色，避免长篇白字黑底。
- 系统中文无衬线。正文16px、辅助14px、课程名21px、页面标题34px/手机28px。主要操作最小44px。
- 半径：按钮10px、文件卡14px、主要面板18px。阴影只用于菜单与轻微悬停层次。
- 交互：控件hover 160ms、面板进入200ms、卡片上移3px与封面缩放1.025；只动画transform/opacity，尊重reduced-motion。禁止全屏假进度、连续闪烁。

## 首页导入
- 首页只完成拖拽/选择暂存 → 显式开始分析 → 真实结果。保留全部逻辑。
- 中心白色大导入面板，简洁橙色文件堆叠图形，边界虚线，底部格式提示与操作栏。
- 拖入时橙色边界及浅橙表面，明确状态；文件卡显示名称/格式/大小/移除。
- 所有上传、重试、未知科目归档、追加/清空保持可用。移动端单列。

## 我的课程
- 维持封面16:9 + 下方名称/资料数量/考试日期。桌面4列、中屏3/2、手机1。
- 原创课程封面改用黑、橙、米白与少量蓝色的图形排版，必须比旧的淡绿色示意图有更强层级。8个科目保持稳定映射。
- 无伪教师/评分/进度。课程排序可选最近添加/名称，若增加控件必须实际生效。
- 整卡可点、编辑按钮独立，键盘focus显著。真实空态/搜索态保留。

## 课程工作台
- 保留返回课程、课程切换、考试设置、练习/卡片及直接添加资料。
- 左侧文件目录，右侧阅读工作区；未打开文件时显示资料缩略卡。打开资料后仍能切换同课程其他文档。
- 阅读区展示原文与出处、提取要点；通过可折叠问答区域提供带来源的课程问答，不编造文档预览。
- 手机文件目录可折叠，阅读区单列，避免三列压缩正文。
- 跨课程切换清空旧文档与回答；资料归属修正/删除后界面同步。

## 验收
- 构建、现有学习/批量导入用例通过；隔离测试数据，不修改真实资料。
- 检查1440、768、390、320px，长中文/英文课程名、空态、搜索、文件切换及待分类。
- 新增分栏的文件选择、问答与移动目录应实测。
