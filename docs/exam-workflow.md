# 组卷、练习与讲解的完整流程

日期：2026-11-05。本轮在既有考谱中新增独立组卷服务与界面，保留原来的专项练习、资料检索、账户和课程工作台。

## 如何使用

从侧栏“练习与讲解”进入，默认打开“智能组卷”。选定课程后可走两条路径：

- **自定义组卷**：选择材料，输入知识点或考察方向，配置单选、多选、判断、填空、简答、计算/证明题的数量、每题分及估计难度。无需的题型设为0，可配置每种题型的具体知识点。预览总题数、总分、用时后生成，单卷1–100题。
- **参照历年真题**：添加本课PDF/DOCX/PPTX，或勾选已经导入的课程试卷。模型分析题型、数量、每题分、方向和估计难度；逐项核对并确认模板后生成仿真新卷。模板可保存复用和重新确认。真题分析有文字预算与抽样覆盖提示，缺图或文字不完整时不能认为整卷已被完整理解。

默认只根据所选课程资料出题；主动选择“允许AI补充与迁移”时，可包含单独标记的AI扩展题。它们可能超出老师考试范围，不伪造原文依据。组卷是分批生成、逐批结构/来源核对，全部完成才保存成卷。页面显示真实已核验题数，可取消任务；不会用占位题或半卷冒充完成。

## 作答到复盘

生成的试卷先保存到本课程卷库，再选择：

- **边练边学**：不限时，先尝试作答，再按需看“方向、下一步、完整讲解”三层帮助。服务端先记录辅助标记，才返回提示与原文。
- **限时模考**：题面和选项可见，交卷前不展示提示、原文引文和正确答案。答题卡可跳题及标记；答卷自动保存，返回卷库后可继续。服务端按截止时间锁定答案，过期交卷只采用限时内已保存内容。

界面保留本机草稿、服务端版本号与保存状态；版本冲突有恢复/备份入口，不静默覆盖其它操作的答卷。交卷需确认未答、标记情况，成功后本轮不可继续改答案；重复提交返回同一份结果。

交卷后可逐题对照自己的答案、参考答案、步骤及评分要点，跳回课程工作台核查原文。可以记录概念、条件、方法、计算、记忆或时间等主要卡点，主观题自评独立保存；选择题目生成针对相关知识点的新复练卷，或收进已有记忆卡片。

“专项练习”仍保留原文回忆/理解应用及错题筛选，“资料答疑”保留按课程提问与原文检索。三者共享课程与材料，采用独立面板状态。题面、公式和解析复用现有安全数学排版。

## 分数应怎样理解

选择题与判断题按固定选项ID核对，多选比较集合；明确匹配的填空可计参考分。简答、计算/证明及无法可靠匹配的填空标为待核对，不能把未评分当0分，也不能根据关键词编一个总成绩。

报告分开显示**可自动核对部分的参考得分**和**待核对分值**。这不是本校考试预测。新试卷作答本轮不直接更新课程掌握度；看提示、已经看过同卷答案或重复练习均不视为首次独立掌握证据。复杂数学答案仍需核查，本轮未引入通用计算机代数证明。

## 实现和开源参考

- `server/exams.mjs`：本项目独立实现的模板、异步组卷、固定题目契约、答卷版本、截止时间、提示和复盘服务；私有答案不进入普通`/api/state`及未交卷题面。
- `src/ExamStudio.tsx`与`src/exam-types.ts`：组卷到复盘的界面与契约；`src/App.tsx`连接课程、原文及现有练习能力。
- 借鉴[DeepTutor的固定契约与未评分机制](https://github.com/HKUDS/DeepTutor/blob/f7aed0744c36c5afef16a4261c31ebee1208cac2/deeptutor/learning/semantic_assessment.py)、[OpenMAIC的稳定选项与客观判分](https://github.com/THU-MAIC/OpenMAIC/blob/1b641161d7f6fa1cacd88c686cfa7592eefe02f2/lib/quiz/grading.ts)，以及[Exam Cram Coach的课程题目与出处组织](https://github.com/ZeKaiNie/universal-examprep-skill)。未复制其整体运行时或品牌。

完整API与限制见 [exam-api.md](exam-api.md)。课程重命名、资料重解析/移动/删除和空间重置，会使依赖旧资料的模板、试卷和答卷失效或清理，并阻止迟到任务提交。

真实联调曾发现模型重写引用或对同一原文片段列多个有效候选而被过严规则拒绝。现在优先提供预编号原文候选，服务端回填真实内容；每条引用先验证，再按来源与原文幂等去重。同段不同原文允许保留，任何非法编号仍拒绝。若模型仍无法提供有效题面或依据，会明确失败并保留配置，不自动补造来源或保存半卷。历年真题实际分析质量仍取决于原件提取、题面完整性和用户确认；本轮模板端到端验收使用合成样卷，不冒称已有真实学校试卷准确率评测。
