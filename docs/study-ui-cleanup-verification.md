# 学习页面配色统一与交互简化

日期：2026-11-05。

## 问题与改动

课程工作台的 `course-orbit-mode` 在 body 上启用独立深蓝主题，覆盖了画布、导航、品牌和顶栏。已移除这些全局覆盖；工作台样式仅负责自身布局，配色沿用共享暖白与橙色。原有文件选择、拖入上下文、笔记生成、产物抽屉和文档阅读功能保留。

练习与讲解去掉大块模考推广卡，把整卷模拟、回忆复习放在工作区标签旁。课程、模式与错题筛选集中排列；出题数量、题型、重点与模型设置按需展开。已有题目时提交是主要操作，生成另一组题为次要操作；未连接模型时提供连接入口。还修复了练习页直接链接与刷新后回到首页的问题。

期末模拟考去掉欢迎大卡片、装饰流程和嵌套入口卡，用简洁的组卷入口与试卷记录列表组织页面。空库不展示搜索和筛选；已有试卷可筛选、搜索、恢复考试与复盘。组卷仅优先展示已启用题型，通过“添加其他题型”展开完整六类题；清空正在编辑的数量不会让该行突然消失。资料选择、指定知识点与题型难度仍可自定义，汇总区不重复抄一遍配置。

## 验证

- `npm test`：354项通过，0失败、0跳过。
- `npm run build`：通过。
- `scripts/exam-ui-smoke.mjs`：10组流程、22项响应式/可读性检查通过，覆盖六种题型、真题确认、100题配置、自动保存、过期交卷和迟到响应隔离。
- `scripts/exam-app-smoke.mjs`：真实隔离后端与合成模型的9组流程通过，覆盖恢复考试、考后复盘、练习/答疑输入保留和练习页刷新停留。
- `scripts/assessment-ui-smoke.mjs`：6组练习流程通过，出题参数、来源帮助记录、反馈恢复和跨课程隔离均正常；未连接模型入口可达，默认收起设置，展开后可调整。390px无横向溢出、无过小的正文与主要控件。
- `scripts/studio-document-ui-smoke.mjs`：7组工作台与文档流程通过，新增实际计算样式断言，工作台与共享画布分别为 `rgb(255,254,250)`、`rgb(246,245,241)`；资料拖入、正常/低动态抽屉、文档阅读及下载保持可用。
- Impeccable机械扫描：无发现。实际页面另核对了课程、练习与模拟考的窄屏效果。

这些浏览器回归使用隔离数据与合成模型，不写入用户试卷、作答或课程资料。当前已登录页面仅进行了浏览和课程选择，没有提交作答或发起模型任务。
