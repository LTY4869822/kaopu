# 考谱介绍页重设计

## Design Read

面向大学生的产品介绍页，采用专业黑白银灰与有实体感的知识纸页，重点是可亲手尝试的复习流程。属于用户明确授权的视觉重做；保留品牌名、介绍页锚点与登录注册回调，不改学习工作台和用户数据。

设计参数：DESIGN_VARIANCE 8、MOTION_INTENSITY 7、VISUAL_DENSITY 3。签名动效集中在资料散开到聚成笔记，其余交互用短而可中断的状态过渡。

## 视觉与内容

比较了温暖纸张编辑版与黑白银灰工具版。选择后者：旧版紫、荧光绿与橙多重争抢注意力；新的近黑背景、银灰文字和白色纸页有一致的任务层级。薄荷色只用于完成状态，不作为满屏装饰。

首屏说明大学生期末复习与资料变为笔记、练习；中段展示资料、对话、产物三个区域；网课区展示时间与讲义的对应；最后说明适用人群与来源边界。没有虚构用户量、成绩承诺或合作学校。

页面主色使用变量，提供浅色外观。交互按钮采用胶囊形，工作区外框14px，真实纸页小圆角，各自对应不同角色。z-index只用于页眉(20)、纸页内部堆叠和焦点提示。

## 动效与响应

- 纸页：按下整理按钮，散开的来源纸页聚拢为复习笔记；再次可反转，动画期间不锁住操作。桌面轻微pointer倾斜，离开复位。
- 流程：普通纵向滚动中右侧工作区保持位置，左侧步骤变化时切换演示；按钮也可直接选择。没有劫持滚轮或自定义光标。
- 网课：时间尺和知识点按钮同步更新讲义，来源提示可展开；均为本地示例，不会上传或生成真实课程。
- 手机：改为顺序内容和直接选择步骤，避免缩小整张桌面工作区。保留320px宽度与键盘路径。
- 动态偏好：系统减少动态及页面暂停开关均取消大幅运动、视差与滚动入场；内容始终可见。通过IntersectionObserver与CSS动画实现，不在每个滚动帧更新React。

## 依据与限制

- [Linear主页](https://linear.app/homepage)：大型产品工作区解释任务关系；本轮能读取结构，动态网站截图访问不稳定。
- [Linear官方设计说明](https://linear.app/now/behind-the-latest-design-refresh)：降低导航与边框的视觉权重，保持克制灰阶。
- [Raycast官方设计说明](https://www.raycast.com/blog/a-fresh-look-and-feel)：核心操作主导视觉，3D隐喻取自产品真实对象。
- Good-fella本次访问停在加载场景，不能宣称复刻其动态参数。本地设计案例库未找到符合motion能力的已审查案例。

应用design-director、clone-website的结构与交互观察方法、design-taste-frontend。此任务是既有React/Vite页面的定制重做，不是建立Next.js像素复刻站；保留现有栈，独立实现纸页动效，不复制参考站品牌或私有素材。

## 实际检查

构建通过。使用ChatGPT内置浏览器在1440×1000、768×1024、390×844与320×800尺寸检查，页面clientWidth分别为1432、760、382、312px（留有滚动条），对应scrollWidth与其相同。检查了深浅外观、笔记成品、练习反馈与窄屏阅读。

实际操作通过：纸页聚合及连续反向切换、资料按课归档与重演、资料多选、空选择禁用、所选来源影响示例笔记、引用展开、错误答案与正确答案反馈、重做、网课时间尺End键与来源定位、FAQ的Enter键操作、登录/注册URL及浏览器返回。

检查中发现并修复5项：非当前步骤正文过暗；手机练习锚点指向隐藏节点；手机缺少当前步骤说明；768px装置负边距侵入文案；手机练习被只读资料和对话推后。最终390px的题目、两项答案和提交按钮可同屏使用。独立审查只读取实际截图，未用静图推断动效。

页面暂停开关实测将纸页transition变为0s；纸页组件另有系统reduced-motion测试。保存了实际动作前、触发后及稳定态的截图和时间记录，记录的是截图请求时间而非显示帧率。不宣称60fps、Lighthouse分数或全站无障碍认证。

完整浏览器日志发现既有登录肖像键盘处理器对缺少key的事件直接调用toLowerCase。补充了字符串校验，忽略无效键盘事件；未改变正常C键交互。保留原始日志，不能将该次检查写成从未出现错误。
