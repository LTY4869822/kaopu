# 整组练习与排版升级

本次将专项练习改为「按题量建立本组 → 独立作答 → 整组提交 → AI 集中讲评」。不再逐题提交或逐题揭晓答案。期末模拟考仍负责整卷、计时和考试报告。

## 实际查阅的设计来源

- [shadcn/ui Progress](https://ui.shadcn.com/docs/components/base/progress)：采用有文字标签和完成数量的进度条，并提供题号导航。
- [shadcn/ui Radio Group](https://ui.shadcn.com/docs/components/base/radio-group)：采用整行可点击、键盘可操作的单选项；以原生 radio 保留无障碍行为。
- [shadcn/ui Typeset](https://ui.shadcn.com/docs/typeset)：参考正文、标题、步骤之间的排版层级，统一阅读行距。
- [Fontsource Noto Sans SC](https://fontsource.org/fonts/noto-sans-sc)：实际安装可变中文字体，随站点自托管，unicode-range 分片按需加载，不依赖用户访问 Google 字体服务。许可见 public/fonts/NotoSansSC-OFL.txt。
- 收藏中的 beUI Tabs / Adaptive Stepper 页面本次通过检索服务无法访问；未将它们声称为已下载的组件。

组件交互和样式在本项目独立实现，没有抓取其他网站的付费素材或整套页面代码。保留暖白、橙色和现有导航。采用题号导航、进度、整组提交、折叠逐题讲评；避免把展示站的动画带入长时间学习界面。

## 行为与边界

- 原文回忆与理解应用都尊重每组 1–6 题。资料不足明确提示，不用重复旧题凑数。
- 选择题、简答题切换时保留答案；浏览器草稿立即写入本机，350ms 后保存到服务端。服务端版本号防止延迟到达的旧草稿覆盖新草稿。
- 每题需作答或显式标记「暂时不会」，全部处理后才能整组提交。提交前练习界面不提供答案、来源原句或历史解析。
- 提交后才调用一次整组 AI 讲评，涵盖学习诊断、逐题解析、解题步骤、来源、后续建议。客观题按保存的答案确定正误，AI 不改答案；简答低置信度保留待核对，所有简答均不更新掌握度。
- 讲评失败保留所有答案，允许只重试讲评。提交幂等、同组并发锁、原子保存和首答计数避免重复作答与重复累计。
- 无 AI 的原文回忆明确显示「原文核对，未调用 AI」；理解应用需要连接文字模型。没有以本地讲解冒充 AI。
- 课程或资料改变会校验来源快照；删除课程或资料会清理相关练习组。内部契约和整组答案不出现在通用 /api/state 响应中。旧单题 API 为兼容既有数据保留，当前页面已不使用它们。
- AI 生成解析仍需结合资料核对，不能保证模型数学推导永远正确。
