## 真实遇到的问题与修改

| 问题 | 修改 |
| --- | --- |
| 新建时要填课程、名称、链接、分 P、范围、字幕格式；保存后还需再次点击整理 | 默认只选课程和导入内容；自动命名、自动识别格式。名称和考试范围按需展开，保存后自动整理 |
| 学生只粘贴链接，直到保存后才发现还缺字幕 | 链接入口先显示真实可用状态；新增可选本地转写，没有可用服务时明确只能保存链接 |
| B 站 metadata 能读取，但字幕接口返回需登录、无字幕 | 在本机已具备模型时，尝试匿名可访问的独立音轨并本地转写。不可访问则失败，不读取 Cookie 或绕过权限 |
| 例题所在字幕与下一条解答被拆开 | 按连续教学上下文归集题干和明确解答，保留全部引用；没有明确拆分标记时保留例子原话，不猜答案 |
| 原文重复显示为概览和正文，读长课需要不停滚动 | 本地整理不再重复“概览”；章节折叠，默认展开第一节；归档移到阅读区上方 |
| 文章中的声画中间稿不能导入 | 支持 Markdown 的真实时间标题与外部画面描述；模型推断和元信息不冒充老师原话 |
| 基础转写模型把“导数”听成“导述”，公式出现重复 F 字符 | 加课程上下文提示和重复保护，保留转写原文；显示自动转写标识、疑似重复提醒，并可回到原课或编辑原文 |
| 更新字幕必须重新找到文件 | “更新原文”预填现有内容；已有起止时间保留为可编辑字幕，不补造未知时间 |
| 公式只能看到 LaTeX 字符 | 新增 KaTeX 排版，失败保留源文；不执行导入 HTML 或加载远程图片 |
| 更新原文后旧记忆卡标识挡住新版知识点保存 | 卡片去重标识包含正文指纹；相同内容防重复，修改后的内容允许重新保存 |

## 文章的价值

[原文](https://mp.weixin.qq.com/s/IYURmdrA06amwqBQbyJAiQ) 最值得借鉴的是 video-downloader 的声画证据层：声音、屏幕文字、画面事实和时间戳共同保留，再交给课程专用整理。我们支持它的中间稿，不把生成 Agent Skills 当成完整课程讲义，也没有安装或冒充运行其视觉模型。

作者仓库的代码、默认抽帧限制及许可证核验见 `docs/research/cangjie-article-review.md`。真实课程仍需题干、条件、公式和推导完整性检查。

## 实操边界

真实样本为宋浩公开高等数学课程 BV1Eb411u7Fw 的 P20“2.1 单侧导数”，约 8 分 32 秒。匿名音频可取、本机已有缓存模型；其他课程或环境不保证有相同条件。首次完整转写 227 段，CPU int8 约 31 秒，专业术语和公式存在明显错误；这不是转写准确率评测。

加课程热词及重复保护后约78秒、144段，仍有错词；14段触发模型核对阈值，不能当作准确率。页面保留“自动转写初稿”。真实页面中已验证定位、课程归档、存卡及重新进入后的去重。口语例子约3:43–5:46，窗口结束可能包含最后一条完整字幕，并不是已经证明例子完整。

声画Markdown另用自编验收稿验证：9段来源完整保留、原课例题只有1个，外部推断不混入例题；题干与解法可分开，数学公式真实排版。非教学的处理说明收进原文，正文显示教学内容。导出含全部原始信息，更新表单预填全部内容。

手机390px无横向溢出，顶部操作合并后首屏可读到正文；电脑与手机均经过浏览器操作。最终80项测试通过、生产构建成功、界面机械检查无发现。

模型连接当前未配置，因此本轮实际跑的是本地转写与原文整理，不能把它称为已验证的 AI 摘要。未识别板书、图形或未念出的题干。字幕覆盖数量只表示处理来源数量，不表示理解正确率。

原课音频、完整转写和验证数据只留在 gitignored 的 `test-results/lectures/`，不打入比赛包。没有读取浏览器 Cookie、登录课程账户或调用云端模型。
