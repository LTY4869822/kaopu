# 考谱 · 明亮且可玩的介绍页

用户明确否定全黑背景及只在按钮点击后改变纸页的上版，要求更有趣的实际互动。本轮替换默认视觉与首屏对象，不以深浅色开关代替重设计。

Design Read：面向大学生的明亮互动产品页。暖白底、墨蓝字、钴蓝主色，浅蓝与柔黄只作物体材质。核心创意是把散落资料亲手吸附到知识中心，而非旋转装饰球。主按钮、标题强调、选中与时间尺沿用同一钴蓝。

考虑过两种方向：带ASCII孔子的浅色艺术站，以及可以拖拽的知识游乐场。选择后者，让学生在页面就能理解资料归科和知识关联；肖像仍留在已有账户页，不覆盖它。

动效语言：物体拖动、磁吸、约束回弹为主交互；按下反馈180至300ms，归位约450至700ms；导航和正文保持稳定，避免整页同时漂浮。滚动步骤与工作台联动；网课图线绘制、讲义换页，并提供用户主动开启的自动演示。自动演示离屏或切后台停止；手动切片立即中断。

减少动态或暂停时保留点选归位、切换讲义、答题等能力，取消大幅运动与自动播放。桌面拖拽支持pointer capture，手机保留点选替代，不能只依赖hover。没有新增外部字体、框架或网络素材。

来源研究单独保存在test-results/landing-bright。当前设计为独立实现；无法进入的原站动效不称为已观察或复刻。实际视觉及交互检查在实现完成后记录。

## 实际检查与修订

构建通过。完整页面在内置浏览器检查1440×1000、768×1024、390×844、320×800；各尺寸scrollWidth与clientWidth一致，无页面横向溢出。首屏、工作台、笔记、手机练习和完整网课主体都有真实截图，见test-results/landing-bright。

实际原生鼠标拖拽命中中心后只收进1份资料；一键归位显示路线，核心按钮Enter可以快速完成和反向散开。组件隔离检查另覆盖区外释放回弹、手机拖拽和系统reduced-motion，报告见test-results/knowledge-garden/report.json。

网课自动演示实测会更换图线和讲义；发现Home键在当前值未变化时可能不触发change，因此补充focus/pointer/key的手动接管，最终实测data-playing=false。页面暂停使知识核心animation为none。登录、注册URL及浏览器返回检查通过，最终浏览器日志无脚本错误。

独立目视审查后加强了拖拽提示，并把中心蓝色‘拾’改为真实可操作按钮。768px文案和装置没有交叠；320/390px没有明显裁断；网课左侧为浅蓝板书、右侧暖白讲义，未保留深色面板。静图审查与动态操作分别记录，不以截图推断动效。

没有测量或宣称60fps、Lighthouse分数或完整无障碍认证。页面演示均为标注过的本地示例，不冒充真实模型生成。本轮没有修改学习资料、模型密钥或后端课程数据。
