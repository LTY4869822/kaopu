# 网课精读运行说明

这是考谱内的实际功能：网课来源 → 字幕／本地转写 → 抽样板书识别 → AI精读与证据校对 → 课程资料与记忆卡。源码和适配器独立实现，实际第三方库、模型与参考关系见 THIRD_PARTY_NOTICES.md。

## 文字和文件导入

运行 npm run dev，登录后打开“网课精读 → 导入网课”。选择课程，粘贴文字或选择文件，点击“整理原文”；配置生成模型后按钮为“生成讲义”。名称、分 P 和考试范围按需展开，文件格式自动识别。导入后自动开始整理，不需要重复点击。

支持 SRT、WebVTT、B 站字幕 JSON、TXT 和 Markdown。单文件 1 MB、25 万字符、最多 5000 段；没有时间信息时不补造时间戳。Markdown 识别真实时间标题和仓颉 video-downloader 的声画双轨，保留画面事实、屏幕文字、外部推断和信息缺口。处理说明与外部推断在完整原文中保留，外部推断不作为原课例题；导入外部画面描述不代表考谱已经识别过视频。

“讲义、例题、原文、板书”分别阅读。AI模式在全部章节基础上合成3–5条速览，合并有确定依据的重复例题。章节折叠，原文与画面保留；校对记录展示原转写、建议和对应图片。原文整理模式只按来源分段、按明确标记归集相邻题干与解法；口语例子最多约两分钟上下文。LaTeX 公式使用 KaTeX 排版，失败保留源文；不执行导入 HTML。

关联 BV 链接后，可回到对应分 P 与秒数。可以导出全部来源、加入课程资料、保存记忆卡。相同内容防止重复存卡，正文更新后允许保存新版；更新原文会预填现有内容，并在保存后重新整理。已有归档资料与旧记忆卡保留。

## 可选本地链接转写

本机已具备依赖与缓存模型，当前 .env 已启用 LOCAL_TRANSCRIPTION=1。其他环境默认关闭，启用前可检查：

    python scripts/transcribe-course.py --check

需 Python、requirements-local.txt 中的依赖及已缓存的 Systran/faster-whisper-base 模型。平台不会自动下载模型。新环境可自行执行 python -m pip install -r requirements-local.txt 并准备模型缓存，再设置：

    LOCAL_TRANSCRIPTION=1
    # 可选指定 Python 可执行文件
    # LOCAL_TRANSCRIPTION_PYTHON=python

重启服务后，“B 站链接”入口显示本地可用状态。粘贴完整 BV 链接或 BV 号，自动读取分 P，点击“导入并整理”。优先匿名可用的平台字幕，无字幕才本机转写。不读取 Cookie 或登录态，不绕过登录或付费限制。当前默认每个分 P 最长120分钟、音频96MB；转写和画面采集分别最多等待30分钟，视频大小和采样帧数仍受原有预算限制。较长课程按分P处理。未读到有效时长与确实超过时长上限分别提示，不把缺失时长误报成课程过长。语音模型可用 LOCAL_TRANSCRIPTION_MODEL 选择已缓存模型，默认auto择优，不会自动下载权重；设备默认CPU。成功后自动继续整理，连接视觉模型且勾选“同时识别板书”时会自动采集和识别关键帧。

取消会停止本地进程树并清理该任务的临时媒体。不可访问、缺依赖或缺模型缓存时显示可恢复错误，可以改为文件导入。本地开关明确启用时优先使用本地转写，不同时调用 BiliNote。

## 可选生成模型或 BiliNote

打开“网课精读 → 模型设置”，分别配置文字摘要与板书识别，可让视觉用途复用文字模型。接口支持OpenAI-compatible Chat Completions；DeepSeek预设为 https://api.deepseek.com 和 deepseek-flash。只有完成真实文字／图片测试才保存配置，不需重启。密钥保存在服务端私有data目录，不返回原文或密钥片段；更换接口不会把旧密钥发给新地址。.env三项仍可作为初始化默认配置。

来源文字和采样图片发送到用户选择的服务，不上传临时图床。全部来源按真实时间交织后分块处理，章节、题目、画面引用分别验证；原转写不被改写。校对original必须来自引用原文，公式缺少画面证据时不自动补猜。无效的可选校对会跳过并提示，未知章节引用仍拒绝保存。文字与视觉已用DeepSeek实测通过；无可用模型时仍可进行原文整理或只采集画面。

2026-11-08起，默认画面采集由纯Node下载适配器和项目内置的Windows x64 FFmpeg完成，用户不需要安装Python、PyAV或yt-dlp。压缩运行时在首次采集时校验SHA-256并解压到私有`DATA_DIR/runtime`；其他系统可通过`LESSON_FFMPEG`指定自行准备的FFmpeg。旧Python链路可通过`LESSON_CAPTURE_BACKEND=python`显式启用。板书页面也可上传一个本地视频或1–12张JPG/PNG/WebP截图；截图可填写按顺序排列的秒数，上传内容只应在有权使用时导入。

“板书”显示真实图片、时间和公式，可以放大核查、只重试未完成的图片。当前采集默认候选间隔4秒、最多96帧，保留变化与时间锚；成功结果按图片hash及模型缓存。全部选中图片识别完成只意味着这些图片均已处理，绝不等同全视频板书完整。人物遮挡、细小符号和帧间擦写仍可能遗漏。

BiliNote 仍可作为独立服务适配，需按其官方说明部署，再填写 BILINOTE_BASE_URL、BILINOTE_PROVIDER_ID、BILINOTE_MODEL，可选 BILINOTE_API_TOKEN。取回的是 transcript.segments 原文，摘要不能代替全文。本机未部署或实测该服务；上游不支持取消时，停止本地轮询不保证上游处理或费用停止。

## 真实检查与边界

已用宋浩公开高数 BV1Eb411u7Fw 的 P20“单侧导数”（8分32秒）实测：15秒窗口的本机base转写约22秒，132段原始文本；48张1080p画面完成真实DeepSeek识别。浏览器重新粘贴链接的全流程首次46张成功，补试2张后48/48成功，最终生成5条整课速览、29条校对记录及有来源的讲义与例题。原始语音仍会错词，识别输出依靠画面证据校对，例如“左倒数→左导数”；原转写完整保留。绝对值例题得到右导数1、左导数-1、0处不可导的正确整理，仍有模糊/遮挡项需对图核查。

自动板书识别已经接入，但不保证任意视频可访问、所有符号准确或题目完整。考试范围参与模型上下文，没有验证过自动考纲匹配。搜课会打开B站搜索；当前是本机单服务、单账户版本。实操问题和修复见 docs/lecture-student-audit.md。
