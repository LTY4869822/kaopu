# 导航与设置整理

手机对应简称为导入、课程、规划、网课、练习、模考，与桌面保持同一顺序。页面标题、面包屑、快捷搜索、导航选中状态也同步更新；各主要页面现在都能通过 page 查询参数刷新恢复。

设置从单一偏好弹窗改为独立页面，分为：

- API 与模型：内嵌原有模型连接表单，配置文字/视觉模型接口地址、模型名、密钥，支持测试、测试并保存及视觉模型复用文字连接。复用已有服务端实现，未重新存放密钥或在浏览器持久化密钥。
- 复习偏好：称呼、默认每日时间、默认复习目标；从原有 /api/settings 保存。每周及单日的复习时间仍由复习规划页面管理。
- 账户与数据：当前账户、退出登录、导出学习数据；清空空间只提供确认入口，仍需在原有确认框中执行。

原有页面内的模型配置快捷入口保留。嵌入和弹窗使用同一个 ModelSettings 表单，避免维护两套 API 配置逻辑。隐藏设置分类保持本次未提交输入；离开整个设置页时清理模型表单内存。

验证：

- scripts/settings-navigation-smoke.mjs：真实应用、隔离 Express 数据、模型接口模拟，3 组交互检查及 15 个响应式布局通过（320、390、768、980、1440）。覆盖 API 测试与保存、密钥输入清空、视觉复用、偏好保存/刷新、键盘标签导航、导出链接、清空确认、导航名称/顺序、快捷搜索。
- 模型服务和基础 API 相关 17 项测试通过；原有整卷模拟 App 流程回归通过。
- TypeScript、生产构建与本次设置组件设计检测通过。
- 构建时发现 LandingPage 缺少 Check 图标导入，补齐了该导入；未改动其布局和交互。
- 测试没有修改用户真实 API 配置、偏好或学习数据。
