# 课程工作台本轮验证

日期：2026-11-05。全部真实模型验证使用本项目编写的合成学习资料和隔离账户数据，没有改写用户现有课程、笔记、答卷或模型配置。

## 已实现

- 首页多科资料读取后调用文字模型判断课程，校验分类引文；复用已有学科或创建新学科。冲突和不足保留待确认，模型不可用时明确使用本地规则。
- 学科三栏工作台：资料多选与拖拽、中间任务对话、右侧笔记及练习卷。手机切换资料／对话／产物，点击选择可替代拖拽。
- 全部所选原文分批处理，笔记按主题整理重复知识点，保留条件、不同例题和出处；疑似错误与冲突标待核对。修订读取完整旧稿并另存版本，原资料保留。
- 笔记作为MD资料保存到同科，可继续引用、答疑、修订及组卷；网课讲义通过原有发布接口进入同一资料区。
- 从所选资料或笔记进入工作台内的出题面板，设置题型、数量、难度和分值；右侧可以重新打开已保存试卷。
- 客观题点选，主观题输入文字或上传图片、扫描PDF、文字文档。识别后先显示草稿，学生确认才采用、追加或明确替换。
- 主观批改保存独立建议分、具体遗漏及薄弱知识点，按真实题本来源返回对应笔记；保持客观参考分和累计掌握度不变。

`node scripts/course-studio-live-smoke.mjs --serve --fresh` 使用已配置模型的只读连接。密钥只在服务端内存中使用，不进入日志、报告或样例数据文件。

3. 从修订笔记生成4道题，覆盖单选、判断、简答、计算四种题型。

这是单组样例的流程验证，不是识别／评分准确率、学习效果或耗时基准。诊断里模型请求的计时仅为响应头延迟，不代表完整生成时长。初轮分类对短物理资料过于保守，补充允许创建新学科及同段多条证据后重测成功；不因此取消待确认状态。初轮批改输出额外topic被严格拒绝，补强字段协议后最终两题首次即返回规定结构。

## 当前边界

首页每批最多100份、每份20MB；笔记单次最多20份、24万字符或400个处理片段，超过时明确要求分批。PDF手写识别每份最多8页；每题作答文字上限10000字符。过量内容不会静默截取后声称完整。

引用真实、正文进入处理、模型自报判断程度都不是事实正确性的证明。笔记的公式、条件、疑似纠错，主观建议分及物理建模仍需核对。主观反馈的文字与建议分也可能不一致，提示词已要求依据固定评分要点、不编造分项分，仍不构成通用数学证明或正式阅卷系统。
