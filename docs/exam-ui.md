# 智能组卷页面

`ExamStudio`接入现有课程、资料原文、模型设置和记忆卡。桌面使用宽答题区与答题卡，手机按顺序单列展示；正文、表单与重要提示保持可读字号，按钮及展开入口不少于44px。课程切换与页面切换保留学习记录，不重置原有专项练习与资料答疑。

## 使用流程

- 自定义：选择课程、知识点与资料范围，按6种题型分别配置数量、0.5分步长的每题分值和难度；支持1–100题、5–360分钟。目标预设会调整默认难度，数量保留并可再次修改。
- 历年仿真：从本课资料中选择真题，或在页面上传PDF/Word/PPTX。分析后展示并允许修改题型结构、考察方向和估计难度；抽样不完整时明确提示覆盖情况。必须确认模板后才能生成新卷。
- 生成：显示分批进度，支持取消。任务ID和组卷草稿保存在本机，刷新可重新查询任务与已保存试卷。即使本机任务指针丢失，也会从课程卷库接口恢复服务端仍在运行的任务。近期失败记录保留可读提示与重试入口；历史完成任务不会强制打断正在配置的新卷。服务重启后任务不可用时允许重试。
- 作答：选择边练边学或限时模考。支持单选、多选、判断、填空、简答、计算/证明题；自动保存、答题卡跳转、标记检查、未答确认。训练提示逐层展开，来源导航前先保存；模考不展示提示。
- 复盘：区分可自动核对参考得分与待核对分值，主观题可对照原文自评；记录错因，选择题目生成新复练卷，或收进记忆卡。记忆卡内容过长时不静默截断。
- 导出：未交卷只下载题面；提交后可下载参考答案、步骤与出处Markdown。

## 草稿与并发边界

答卷采用服务端revision乐观并发；请求中的旧课程/旧答卷响应不会覆盖当前页面。自动保存进行中仍可输入，后续输入会再次保存；旧答卷保存完成后也会更新相应本机草稿版本，避免返回课程时丢失较新输入。版本冲突时保留备份，提供显式恢复或下载入口。

组卷配置在组件state惰性初始化阶段先读取、校验对应课程缓存，再允许持久化，避免React StrictMode的effect重放用默认值覆盖已保存的题型、名称、知识点与时长。切换课程时，旧课程的配置不会写入新课程缓存。

限时结束后编辑被冻结，交卷按服务端限时内已保存答案处理。若最后输入没有及时上传，本机另存可下载草稿，不混入该轮成绩。等待自动保存后执行交卷或提示，会再次检查课程和答卷标识；等待另一门课的保存不能视为本课已保存。

## 组件隔离验收

运行 `node scripts/exam-ui-smoke.mjs`。它创建独立Vite组件环境并mock全部API，不读取或修改用户账户、课程资料或模型配置。结果在 `test-results/exam-ui/report.json`。

2026-11-05已通过8组流程、9组响应式与可读性检查，1440/768/390px无横向溢出，受检正文/标签/重要提示无小于14px，按钮与summary不少于44px，浏览器页面错误为空。整个组件harness运行于React StrictMode，并验证了组卷配置卸载重挂后保留六题型各1题、名称、知识点与25分钟时长。其余覆盖六题型、自定义配置、真题确认与超过40题配置、保存刷新恢复、提示后辅助标记、主观待核对、自评/错因/卡片/复练，以及三项关键竞态：限时到期仍有未存答案；旧保存未完成时父级切课且新课请求提示；旧listing迟到不能清空最新卷库或模型状态。模型生成任务失败时，界面以错误提示展示、清除任务恢复标识、保留组卷配置并允许重试；取消采用中性反馈，不冒充成功。本机无任务指针时可从服务端恢复active进度，完成后打开已保存卷；再次读库中的历史completed不会把新卷配置切走。

这些检查使用虚构题面与确定性mock，验证交互及数据流，不代表真实模型生成质量或考试预测准确率；整体服务与真实生成由主集成验收另外核查。
