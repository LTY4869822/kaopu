# 网课精读整课重编与配图筛选

日期：2026-11-05。延续 [开源研究](research/lecture-reading-redesign.md) 的来源保全、时间对齐和课程内引用设计；没有复制第三方实现或引入新模型权重。

## 本次实现

1. 保留原始字幕、99段分块讲义、原始例题与全部截图，另外生成可追溯的阅读版本。
2. 按整课知识目录重新撰写正文，避免串接分块AI扩写。正文、核心结论、少量易错点和可折叠AI解释分别呈现。
3. 对原课例题进行语义分组，校验每个原例题ID恰好保留一次。采用完整来源作为题干基准，缺条件时保持待确认，不生成确定答案；额外假设必须显式标注。
4. 独立教学校对检查概念和条件。图文匹配完成后，再核对正文、核心结论、易错点与实际选中画面的内容是否一致。
5. 截图先按真实来源范围召回，再由视觉模型实际看图，逐张记录清晰度、完整度、相关性和理由。正文仅使用通过筛选的原图；空白、过渡、遮挡或未写完的画面不自动插入。未找到可用画面时明确缺口。
6. 新采集器兼顾时间覆盖、清晰度、变化后的稳定画面和感知相似度去重。它只产生候选，不能保证板书完整；最后仍需视觉筛选。
7. 支持独立重编、按阶段进度显示、取消与断点续编。原文/画面/题目变动会使旧重编失效。重试配图复用已有正文和题解。
8. 讲义、导出、课程对话与归档共用阅读版本。PDF不再展开全部原始分块；嵌图HTML仍可折叠查看原始片段，Word保持连贯正文。

## 真实样本

- 高等数学第1讲，B站P3，约65分钟。
- 99段原始讲义 → 10个知识单元；17个例题片段 → 13道课堂题。
- 取整函数两片段、x²单调性两片段、狄利克雷函数三片段分别归并，保留全部来源ID。
- 手工对照了取整函数、狄利克雷函数和奇偶分解的选中原图，确认截图中有对应题干。取整负数示例与原图的 -0.9→-1、-3.8→-4 一致。
- 独立教学校对实际发现并修改了常值函数定义域、sgn原点图像、上下界符号、单调区间端点、狄利克雷函数周期取值、复合表达式定义域等问题。

- `test-results/lecture-editorial/`：运行报告、前后数据快照、桌面/移动截图及实际讲义导出。包含用户课程内容，不作为公开素材。

## 验收边界

这次完成的是一节真实高数课程的内容与交互验收，不代表所有学科的正确率或完整率。原片抽样仍可能漏板书，视觉筛选与教学校对仍由模型辅助。条件不确定时保留待核对项，原始资料可回查，不能把“处理完成”当成内容已被形式化证明。
