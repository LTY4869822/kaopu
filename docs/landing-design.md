# 考谱公开介绍页 · 2026-11-05

## 用户否定首版后的新方向

用户明确指出暖白纸张首版过于普通、缺少创意，要求配色、交互和趣味显著升级。首版取舍在下面保留作历史，不代表现行界面。

现行方向是“期末复习游乐场 / 知识引力场”：深海军蓝#141421作为主场景，酸柠檬#dcff70表示行动，浅紫#b7a0ff表示知识与路线，珊瑚色表示尚未消化的网课片段。配色跨整页延续：深色首屏→酸柠檬卡点导航→浅紫滚动学习路线→深色网课切片机→亮色练习召回→浅紫注册收尾。

首屏改为独立CSS3D“拾”键和知识碎片，鼠标移动改变视角，点击／键盘按键令碎片聚拢归队。原生Canvas只画43个知识符号，离屏和后台停绘，支持暂停与减少动态；不是下载的3D资产，也不是实时AI任务。全部结果标注交互示例，不写真实资料。

网课部分新增原生三段时间尺：拖动或键盘选择00:00、02:31、04:23，左侧板书与右侧来源同步变化。保留讲义／例题／板书标签与展开解法；用交互解释“长课可以按知识点读”。

Codrops作者的Ten Years Away公开站点已实际打开，观察到巨型边缘排版、低明度蓝色开场与点击后切换明亮漫画章节。借鉴章节变换与主体驱动的交互，不复制插画、品牌、WebGL代码或滚轮接管。

桌面原生滚动以requestAnimationFrame合并读取三章位置，同一预览跟随当前章节；不使用按视口宽度解析的百分比rootMargin。手机每章有自己的紧邻演示。认证仍使用原有服务，未登录首先进入介绍，`?auth=login/register`可直达，已登录用户可用`?intro=1`重新看介绍。

## Design Read

面向资料零散、课程多、时间紧的大学生。访客首先需要知道这是期末复习平台，再看到资料、计划、练习和网课精读如何接起来，最后创建账户。已有登录页的孔子字符交互保留。

选择“把知识拾回来”的纸张叙事：暖白纸面、墨黑大字、信号橙标记；散落的讲义向课程文件夹收拢，再成为一天的任务与可翻面的记忆卡。此概念贯穿首屏和三段滚动演示。另一方向是全黑科技感大屏；未采用，因为会弱化学生资料与阅读的产品语义，并与登录页重复。

桌面：顶部轻导航、左右非对称首屏、整行问题条、左侧分章讲述与右侧sticky演示、反白网课阅读展示、常见问题、橙色大收尾。手机：普通纵向文档，每章紧邻对应演示，避免固定巨幅场景占满屏。主按钮始终有明确的注册／登录结果。

字号按中文重新排版，不下载大体积字体。正文16–18px，标题使用系统黑体，少量数字用等宽；边界与橙色细节承担装饰，不放虚假用户数、评价或提分指标。全部产品预览标注演示，示例不产生真实学习数据。

动效：首屏纸片轻微错位聚合；滚动时章节与展示同步，进度线提示关系；卡片翻面、任务勾选、网课标签与来源定位均可操作。普通滚动，不接管滚轮。只使用transform/opacity；离屏及减少动态时停用循环，内容保持可读。不承诺帧率。

## 可验证的产品边界

导入PDF/Word/PPT、课程归档、来源回看、跨科复习计划、资料练习与间隔复习已在仓库存在。网课流程支持匿名可访问的链接／字幕、抽样板书及AI整理，不承诺任意视频或全部公式完整。当前为本机单用户版，不宣传云同步、团队协作、保过或命题预测。
