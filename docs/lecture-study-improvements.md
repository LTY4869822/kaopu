# 网课精读的复习流程整改

2026-11-05。范围是考谱已有网课功能的可用性修复，不替换账号、课程库、解析栈或模型服务。

## 对照项目与取舍

- [CoursePilot](https://github.com/wansui976/CoursePilot)：参考课程内阅读、带出处问答、学习记录和练习联动。
- [course2md](https://github.com/mizorewww/course2md)：参考图文讲义优先、原始画面和时间对齐、可保存的阅读成果。
- [BiliNote](https://github.com/JefferyHcool/BiliNote)：参考分阶段视频处理、原片跳转和失败后的继续处理。
- [Open Notebook](https://github.com/lfnovo/open-notebook)：参考来源范围、资料选择和引用回查。

本轮查阅官方说明，结合之前的源码研究进行独立实现；没有复制这些项目的源文件、安装整套服务或引入新的依赖。不把上游项目的宣传效果当成中文数学准确率。已有第三方依赖、ASR和模型服务仍按 THIRD_PARTY_NOTICES.md 标明。

## 已实现

1. **可操作的待完善清单**：未识别画面、视觉不确定处、待确认题干、待补题解、需回听转写、最长的画面间隔分别显示。点击可去原图/原文/具体例题、重试识别、补题解或预填补采范围。较长间隔只是可能有遗漏，不伪装为已确定的内容缺失。
2. **按时间补采**：填写 mm:ss 或 hh:mm:ss，一次1–120秒、最多12张，整个讲次最多120张。使用真实视频绝对时间；追加画面保留已有帧ID、文件hash和已识别结果。识别缓存未变时只调用新画面，取消或验证失败不会覆盖原图。当前仍需重新取得视频媒体，不能把分段补采宣传成只下载指定的几秒。
3. **旧讲义保护**：采集与识别不再清空已有讲义。画面变更时标明等待更新，保留旧正文；更新前不把旧引用链接到新的画面，也不允许旧讲义归档、生成练习、图文导出或继续来源问答。重新整理成功后才能使用新证据。失败时旧正文仍可阅读。
4. **阅读与自主标记**：知识点可标已读、需巩固，例题可标已练或需巩固，并可记到当前内容。服务端保存，刷新后可继续上次阅读。只看需巩固筛选可以集中复习；移除最后一个标记后仍可返回全部内容。这里不是自动评分，也不据此增加掌握率。
5. **内容变化后避免假进度**：记录引用当前知识点/例题的内容签名。内容变化后不继承旧标记，未变化的内容保留记录。过期页面写入会收到409提示并可重试刷新。
6. **先练再看解法**：课堂例题原课解法与AI补充讲解统一默认折叠，跨讲次或重新整理后不继承已展开的答案。
7. **从讲义到练习再回查**：练本课会显式归档当前讲义，按稳定documentId复用资料，预选它打开期末模拟考。题型、数量和难度使用现有组卷功能。练习来源若来自网课，点击原文返回对应讲次的知识点/例题，而不是只打开整份归档文本。
8. **首次进入修复**：修复ExamStudio在React StrictMode重放课程初始化后跳过首次资料选择的问题；课程重置后重放进入意图，普通组卷编辑不会被反复预填覆盖。

## 验证依据

- `tests/lesson-study.test.mjs`：清单不改原稿、标记幂等、版本冲突、变化后取消旧进度、重启持久化、课程边界、登录保护、补采保留旧讲义、更新前阻止归档/导出。
- `tests/lesson-vision.test.mjs`：真实文件hash校验、追加保留旧帧/缓存、只识别新增画面、错误范围拦截和失败清理。
- `tests/extract-lecture-frames.test.py`：合成12秒本地视频实际解码，补采3–8秒，验证绝对时间、尾帧和范围校验。无本机模型调用。
- `scripts/lecture-study-smoke.mjs`：完整React页面、真实隔离Express API与临时资料库；学习标记、重载、继续阅读焦点、弱项筛选、答案折叠、范围表单、真实归档及练习入口、手机布局。考试模型为确定性测试服务，不代表真实出题质量。
- `scripts/lecture-reading-smoke.mjs`、`scripts/lecture-layering-smoke.mjs`：原有目录、图文阅读、来源定位、课程对话、取消、跨课隔离、图片鉴权、字号与键盘交互回归。
- `scripts/lecture-supplement-live-check.mjs`：对用户已有公开高数视频，在隔离目录补采165–177秒。原有48张保留，新增5张全部完成真实视觉模型识别，识别总数53；原始lessons.json字节hash不变。报告位于 `test-results/lecture-study/live-supplement-report.json`。这不证明全课覆盖或数学正确率。

## 保留的限制

单讲仍有120分钟、媒体大小和采样预算限制；B站匿名不可访问的内容仍需要合法可用来源。清单是结构与证据检查，不是知识正确性证明。手写、遮挡、小字、快速擦写仍可能漏识别；模糊题干不会自动猜全。真实中文课程的系统质量评估仍需分学科样本与人工对照，不能用测试通过数替代。
