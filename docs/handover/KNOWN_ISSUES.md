# 已知边界与后续优先级

这些条目是交接边界，不代表测试失败被当成通过。

## 对外部署前

1. 当前只有一个本机账户和 JSON 文件持久化。多人 SaaS、数据库事务、租户隔离、云存储、限流/配额、监控和部署恢复需要专门建设；不要直接将测试工厂暴露公网。
2. API 密钥在本机私有文件中保存，不是加密凭据服务。正式托管需加入密钥管理。HTTPS 代理环境应配置安全 Cookie，并检查代理与文件权限。
3. JSON 导出不是包含原件和账号的完整备份，也没有通用导入 UI。优先建设经过校验、可回滚的数据迁移流程。

## 下一轮重点验证

- 长视频全链路：本轮真实模型使用短合成字幕；没有重新跑多小时真实网课。用有字幕/无字幕、不同分 P、公式密集、老师遮挡、板书渐写和跨帧题干建立样本集。录屏/下载/识别可用性受来源平台与本机依赖影响。
- AI 内容质量：377 项自动测试验证协议、来源与状态边界，不能证明模型数学推导、截图相关性或组卷难度准确。需要人工标注样本与可量化评估。
- 任务恢复：进程重启后的在途任务会中断，记录和输入保留，不承诺后台自动续跑。可建设持久任务队列、租约与重试预算；保留取消/过期来源拦截。
- 可选 Docling/ASR：包内只有依赖清单，没有现机虚拟环境和模型权重。在目标机器单独验证安装、资源、离线能力与处理时长。
- 大批量/极长资料：已有数量/字符/大小上限，但本轮人工体验未穷尽 100 文件、100 题和全部最大视频场景；边界主要由自动测试覆盖。

## 产品与维护优化

- 组卷配置仍可进一步逐步展开，尤其真题尚未分析时不必强调默认卷面结构。
- AI 归科的自由文本理由偶尔包含 `courseId`、`null` 等技术词，展示文案还可进一步整理为面向学生的简短说明；保留原始证据用于核对。
- 数学文本中纯数字的单美元写法为避免货币误判可能保留原样；复杂公式、跨行 TeX 与扫描符号需要继续校对。
- 页面/课程已有 URL 定位；具体讲次、章节、阅读页等更深状态仍可扩充可分享链接。
- `App.tsx`、部分 CSS 与试卷模块较大，建议按领域渐进拆分，保留现有回归与公共契约。
- `npm ci` 会提示 `pagedjs@0.4.3` 的传递依赖 `@babel/polyfill@7.12.1`、`core-js@2.6.12` 已弃用。当前安装、构建和测试通过，后续升级排版链时要验证目录、页码和数学分页，避免只为消除警告改变输出。
- 长文档仍应抽检章标题、长表格与正文的跨页关系；可编辑 Word 的目录字段在目标 Office 中更新，不能假定不同 Office 版本分页完全一致。
- 当前 UI 脚本包含历史实现与旧端口。交接后优先统一脚本入口配置，淘汰旧工作台脚本；现行文档/版本恢复脚本已直接用隔离生产构建。
- 历史 `docs/` 文档个别措辞/截图可能对应旧版，当前事实以 `HANDOVER.md`、本目录记录和源码为准。

原用户运行数据留在原电脑。若后续需要迁移，由所有者另行授权并安全移交完整数据目录；不要为了复现问题修改或清空原用户数据。
