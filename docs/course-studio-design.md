# 课程工作台设计记录

日期：2026-11-05。实现文件为 `src/CourseStudio.tsx`、`src/course-studio.css`。原件阅读与手写校对复用既有 `CourseWorkspace`，主导航和课程页外壳由 App 保留。

## Design Read

学生的主要任务是把本课分散资料变成可读、可复用的笔记，再据此练习。信息层级按照「输入资料 → 下达指令与真实进度 → 保存产物与出处」排列，而不是用统计卡片替代工作。

采用一张有边界的三栏工作台：左侧资料抽屉、中间对话、右侧成稿。左、中、右的对齐顶栏和细分隔线维持定位；产物以纸页形式展示。主视觉是从散页到成稿，留在空状态的原创 CSS 纸张线稿，并延续到右侧笔记纸页、来源标记和全文阅读。

视觉采用暖白纸色、浅鼠尾草色和深灰绿文字，既有黑色导航外壳与橙色全局操作继续保留。工作区内以灰绿标识已选来源、连接状态与发送动作；不使用自动闪烁的背景、炫光或密集装饰卡片。常规正文14–16px，阅读展开页16px，重要操作均有图标与文字。中文使用项目既有系统字体，不新增字体下载。

对比过两种关系：①直接让对话全屏，资料和结果都藏抽屉；②三栏并列，资料、当前任务和成稿同时可见。桌面采用②，因为多资料整合需要持续确认输入，右侧产物需要随时再拿来做题；窄屏采用顺序化的资料／对话／产物三页签，避免把桌面整体缩小。

## 行为和状态

- 资料多选与本次对话来源共用一个状态；勾选后可见来源标签，标签可移除。内部拖拽携带课程和真实文档 ID，服务端继续验证。一次最多20份，超限明确说明。
- 拖拽有虚线落点反馈；同时提供勾选和「去对话」，不要求学生一定使用拖拽。原文件预览与勾选按钮独立。
- 输入区可切整理笔记、答疑、出题；出题会打开复用的练习配置界面，设置题型、数量与难度。生成笔记、修订和答疑均调用真实后端任务，没有假数据或假完成百分比。
- 加载、空状态、处理中、失败、取消与完成均有对应界面。取消使用真实 DELETE 接口。失败保留指令记录，网络状态丢失后允许重新查询任务；未配置模型时有连接入口。
- 右侧保留笔记版本和真实试卷列表；笔记可全文阅读、来源定位、Markdown导出、加入对话、修订及据此出题。练习面板关闭后按 `refreshKey` 重新查询真实试卷。
- 笔记正文仅解析受控 Markdown 子集，公式复用 KaTeX 组件；没有将模型正文作为HTML插入，不加载正文里指定的外链图片。引用按钮打开同课程的真实原文及对应页／片段。
- 已变更的来源明确提示重新核对。覆盖状态只说明所选全文已送处理，不表示事实正确率。
- 原件与全文以原生 dialog 展示，具有关闭、Esc 和焦点返回。手写资料依然可以逐页校对。

## 动效意图

高频状态只在140–180ms内改变边界、颜色或少量位移，帮助理解选择／发送，不延迟执行。拖拽落点是稳定边框；没有模拟物理回弹。仅真实请求处理中有一个状态旋转图标，减少动态模式下保持静态图标和文字状态。消息更新不强制滚走正在阅读历史的学生，提供「查看最新消息」。

## 验证边界

本文件先记录实现决策，不冒充浏览器验收。最终需要实际验证1280／1440桌面、390手机、长文件名、多选拖拽、资料引用、生成完成、取消、失败重试和减少动态模式；由主任务运行最终构建与浏览器体验检查。尚未观察到的状态不记为通过。

主任务提供了真实1280×720截图`docs/screenshots/course-studio-before-polish.png`，本设计子任务已看图确认：650px列高让发送按钮落在首屏以外；部分辅助字过小过淡；右侧标题和正文首标题重复。已据此将桌面最小列高改为470px，手机为视口减去外壳和底部导航的可用高度；关键辅助字至少12px并加深，正文15px；笔记预览仅隐藏同名首标题，导出原文不变。另修正首次默认显示最新笔记以及工作台纯数字数学标记。修正后的截图与操作仍由主任务复验，不把源码改动当成已通过视觉检查。
