# 图文网课精读与课程对话验收

日期：2026-11-05。用户要求：修复识别完成但原图无法显示，将网课转换为带截图的完整教学讲义与详细习题讲解，增加能够读取当前课程的API对话。

## 参考与实现

参考[BiliNote](https://github.com/JefferyHcool/BiliNote)的字幕/ASR流水线与时间戳图文笔记，[Open Notebook](https://github.com/lfnovo/open-notebook)的来源作用域及上下文预算。另核验VideoRAG、PySceneDetect、WhisperX的代码与许可，详见[研究记录](research/lecture-reading-redesign.md)。本次没有安装它们的模型或复制整套项目。

本项目保留当前可用的字幕、本地ASR、采帧与视觉识别通路，新增整课阅读编排、教学结构、课内检索对话和离线图文导出。原始段落与截图不因知识归并而删除；真实截图以frameIds关联，不用最近时间帧冒充题图。目录模型必须给每个原章节唯一归属，映射无效时使用可追溯的保守目录。

知识直觉、先修条件、教师式解释、步骤、易错点与自测为可选结构，缺证据不硬填模板；AI补充解法与原课解法分开。无完整题面时保留待核对。旧讲义兼容，用户可通过“完善讲解”复用既有来源更新教学层。

## 图片故障

实际文件仍在：当前P3原图为有效JPEG，API经3001/5174均能返回200图像。浏览器旧会话直接访问图片时返回401，原img错误处理仅隐藏图片且永久记录失败，没有会话恢复提示。

新共享组件通过same-origin凭据读取图片Blob，区分401、404、超时和图片格式错误；会话失效统一交给应用处理，临时失败支持原位重载，恢复联网可重试。图片缓存有大小/数量/时间预算，放大在同页焦点受控窗口完成。识别数量与图片加载状态保持独立。

人工抽查发现的表达边界已在派生阅读层修正：常值函数的定义域/值域；复合函数在整个D_g上定义与自然定义域的区别；y=x²的零点特例不可推广为任意端点不影响单调性。另对模糊题干详细解前置条件假设；e^x在R上无界的补解统一以M>0、x=ln(M+1)构造严格大于M的函数值，0是下界及下确界而非唯一下界。原稿保留，规范阅读层进入检索，不把旧错误作为另一候选重新送模型。以上有正反、幂等、原稿保全测试（派生文档专项27项），不代表全课数学准确率。

数学窄澄清只处理已验证的特定误解，不是通用数学证明器；48张画面也不是全视频板书完整覆盖。模型讲解与解题仍需回到所引来源核对。
