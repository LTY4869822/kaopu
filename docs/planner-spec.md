# 复习规划助手实施约定

## 范围与使用场景
扩展现有复习计划页，沿用已确认的内部黑白橙系统。学生提供考试安排、准备起点、每周可用时间、科目难度、当前掌握和目标；助手生成可执行的跨科任务。支持临考准备、及格优先、均衡提分和高分目标。

## 核心任务
配置课程与时间 → 查看日期安排 → 在每日任务或时间线之间切换 → 开始学习或记录完成 → 按最新条件重新分配。用户可以为某一天设置更少时间或休息日，避免要求每天都同样空闲。

## 首屏与信息层次
页面标题保留“复习计划”。首屏先呈现模式切换和规划调整入口，再呈现周日期与当天安排。右侧为规划助手，说明真实时间缺口、最近考试、工作量是否来自估算。配置在当前页展开，不把日常学习操作埋进多层弹窗。

## 数据与算法
采用 Node 原生滚动排期，参考开源项目的截止日、容量约束与重排方法；FSRS继续负责记忆卡。每科剩余工作量优先使用用户输入，未填时明确标注估算。任务受日预算和准备起点约束，已结束考试不新增任务；时间线在可用窗口内分块并插入休息，不重叠。超出时段容量的任务明确显示未排入分钟。算法没有经过成绩预测校准，不声称全局最优。

## 交互与状态
两种模式共享任务和完成状态；完成历史保留原始分钟。编辑表单显式保存，状态改变后重算；旧请求不能覆盖新日期。提供加载、错误重试、无课程、未设日期、零预算与容量不足状态。日期、模式、表单与任务可用键盘操作。现有专注计时继续可用。

## 视觉与验证
中文正文16px、主要辅助14px，表单按任务分组。桌面安排区与助手并列，手机按优先顺序纵向排列，周日期采用七列网格并可翻周浏览。参考用户收藏的 BoardUI Calendar、beUI Timeline/Motion、21st 分段控件与折叠模式，使用原创代码实现。

验证包括预算、截止日前缀容量、起点、时间窗、休息、完成/撤销、输入校验、重排和数据持久化；浏览器检查1440、768、390、320px。测试使用隔离数据。
