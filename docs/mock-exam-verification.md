# 期末模拟考验收

日期：2026-11-05。用户确认将独立知识/记忆卡片栏目替换成期末模拟考，现有组卷作为考试准备步骤，并要求参考多个开源项目、精修视觉和交互。

## 本轮完成

- 桌面侧栏、手机导航、快捷搜索新增统一“期末模拟考”；练习页保留专项练习、资料答疑及进入整卷模拟的入口。
- 课程工作台的来源出卷、旧试卷以及网课归档入口进入同一全页ExamStudio，带入课程、资料或试卷ID。StrictMode重放和切课有入口消费与版本隔离验证。
- 暖白/橙色准备面板、两种出卷方式、真实课程资料数、未完成考试恢复、试卷搜索及全部/未完成/已交卷筛选。记录显示客观参考分与待核对分值，不合成为虚构最终成绩。
- 开考准备明确计时与保存规则，限时模考为主动作。刷新/切页不暂停，按服务端截止时间锁定答案；到时自动尝试交卷，失败可以重试，未在时限内保存的本机草稿单独备份。
- 考后提供详细讲评、错因、主观AI建议、来源回看与变式复练。重新打开历史答卷时默认选中错题、未答题和学生自评待订正项。
- 最近一份来源有效的已交模考进入滚动规划，按已有考期与分钟预算安排订正，任务直达原答卷。新一轮已完成模考覆盖旧依据；学生确认已订正、资料变化、跨课及试卷契约变动均有验证。AI建议不单独当作错误证据或修改掌握度。
- 卡片数据未删除，保留练习页“回忆复习”和规划中的主动回忆任务；旧卡片创建与读取真实可用。
