## 当前可见差距

1. 结构主要依赖模型生成Markdown，小节容易机械重复“定义／公式／步骤／自测”。有更多小标题不等于有更好的教学组织。
2. 定义、条件、推导、例题题干与解答没有完整的文档语义模型，PDF和Word主要靠标题、段落及表格样式区分。版式仍属于自制基础讲义，不能称为成熟模板的同等效果。
3. 原有实测为一节约8.5分钟的高数课及1310字符的合成线代资料；本轮另用平台已有约65.7分钟高数课，对10个知识章节的完整转写与已有画面识别做逐项核对，并复查了两道既有例题。仍有原课证据缺口，且未运行上游同课对照。这不足以证明多小时网课或其他理工课程的普遍质量，详见[本轮记录](lecture-content-quality.md)。
4. 来源ID被处理、抽样画面识别完成、文件成功生成，分别不等于知识点没有遗漏、题面和公式正确、版式精美。
5. 最新源码的工作台颜色已由共享样式改为暖纸色与橙色，旧验收截图记录的是此前深色版本。旧图不能继续作为最新源码视觉验收证据；本轮不覆盖这些后续样式改动。

## 后续可证明的对照

以一节真实理工课和一组真实复习资料为输入，记录上游版本、使用模型、转写／OCR输入及生成设置。先对照题目、条件、公式、推导和来源是否保留，再并排比较实际文档与任务操作。没有实际运行上游的项目标“未测”，不能补写分数或“已追平”。

本轮361项测试与浏览器流程检查作为工程回归记录使用，不作为“开源项目效果一样”或教学质量的证据。用户已明确优先解决网课精读的内容质量和完整性。
