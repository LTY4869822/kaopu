# 练习工作台精修验收

日期：2026-11-05。方向由用户确认：暖白＋橙色，清爽的专业学习工具。

## 实际修改

练习与讲解的页头、标签导航、课程栏与表单重新对齐。组卷页移除欢迎插画及大块装饰留白，题型采用桌面紧凑表格、小屏逐项展开。试卷确认页采用文档式布局；复盘分开呈现客观参考得分与待核对分值。专项练习与资料答疑同步统一表面、字号、选中状态与来源阅读。

答题卡在手机默认折叠，交卷按钮保持可见；键盘可展开，跳题后聚焦题面。交卷弹窗约束焦点，Escape与继续检查会恢复触发处焦点。隐藏文件输入退出Tab顺序，仍由可见的上传按钮打开选择器。

共享控件主色 #c7502a，白字对比度约4.56:1；次文字 #6e7069 对画布约4.97:1。正文16px、题面20px、辅助说明14px，常用目标至少44px。平板出题设置提前在980px以下转单列。

本机收藏与具体官方参考见 [参考记录](design-references/practice-polish-bookmarks.md)。没有新增组件框架或执行收藏中的外部技能。

功能验证涵盖六种题型、自动保存与恢复、限时到期、辅助练习、主观题待核对、确认交卷、错因记录、收进记忆卡、复练、真题模板分析与确认、三工作区输入保留、生成中取消和迟到响应隔离。手机另核对答题卡键盘展开、跳题聚焦、交卷一直可达、弹窗关闭恢复焦点。

所有业务自动化使用隔离临时目录和固定测试模型响应，没有修改用户课程、资料、试卷和答卷，也没有为验收调用真实付费模型；这轮不重新评估模型生成质量或文档解析算法。

## 机械检测的窄范围保留项

检测报告：`test-results/practice-polish/design-detector.json`。唯一告警为 `src/ui-system.css` 中既有 `.flashcard` 的4px底边与圆角组合（`border-accent-on-rounded`）。它属于此前ThreeUI纸层记忆卡材质，未在本轮练习界面精修中更改；不是新增练习卡片的强调边。此处记录范围和原因，不把机械检测描述为全部零告警。
