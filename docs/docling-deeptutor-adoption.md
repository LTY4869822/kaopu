# Docling与DeepTutor思路接入验收

日期：2026-11-05。接入现有考谱学习空间，保留批量导入、课程工作台、复习计划、网课精读及本地账户流程。

## 现在可以怎样使用

1. 首页添加资料，选择“自动读取”或“版式增强 / OCR”，再点“开始分析”。自动读取优先快速提取文字，文字不足或覆盖不足的PDF再尝试本机Docling；增强模式直接使用Docling的PDF、DOCX、PPTX管线。
2. 自动归类后进入“我的课程”的相应工作台，阅读摘录并查看原文件。新上传原件保存在受登录保护的数据目录。PDF有实际页码，PPTX有实际幻灯片号；Word按节定位，不编造物理页码。
3. 打开“练习与讲解”，选定课程、切到“理解应用”，选择1–6道题及单选/简答，可填写练习重点。该模式使用页面内已配置的文字模型；“原文回忆”仍可离线使用。
4. 独立作答后查看参考答案、分步解释及原文依据。“查看原文”会返回课程工作台并定位对应段落。离开再回来，可点“回看上次反馈”；这不会新增作答。

Docling实际安装于项目隔离环境，模型保存在本机，读取文档时不自动下载模型。DeepTutor为设计参考，当前出题、来源核验、答卷保存和界面由本项目独立实现，未安装其整套运行时。版本、安装方法及上游许可分别见 [Docling说明](docling-integration.md)、[练习API说明](assessment-integration.md)和[第三方声明](../THIRD_PARTY_NOTICES.md)。

## 核心处理约束

- 生成先形成知识点蓝图，再形成固定题目与答案契约。引文必须与当前课程实际片段相符，页码等元数据从资料复制，不能采用模型自行编造的出处；整批通过验证后才保存。
- 公共题目不带答案键、评分规则或解析。提交后展示反馈；曾查看来源、历史反馈或已有作答的题，不再按独立首答累计掌握度。
- 单选使用保存的选项ID核对。简答反馈保留“部分符合”和“待核对”等状态，所有简答均不更新掌握度；模型自报置信度不视为评分准确率。
- 资料重新增强解析、移动或删除时，关联理解题会失效/清理，避免旧题继续引用变化的原文。取消、迟到响应及课程切换做隔离，避免跨课程显示结果。

## 本轮实际验证

- Node后端全套156项通过；最终Docling与根服务集成18项重跑通过。覆盖来源与答案隔离、首次计数、辅助/重复作答、资料级联、原件认证和异常路径。构建`npm run build`通过，保留现有资源体积提醒。
- 合成Word与两页PPTX真实解析通过，包含2×2表格、章节/幻灯片与结构来源。
- 合成中英扫描PDF经真实HTTP上传、自动OCR、创建“线性代数”课程、结构保存及原件下载的完整流程通过。得到第1页的3个片段，包含“线性代数期末复习”“矩阵乘法需要检查维度”和英文矩阵乘法说明；每段具有块引用和坐标。原文件下载逐字节相等。该次含冷启动总68.7秒，是单次观察，不是性能承诺。报告：`test-results/integration/docling-http.json`。
- 理解练习隔离浏览器测试通过：数量/题型/重点、模型未配置、待核对、来源导航、历史恢复、重复操作保护和异步隔离；390px手机无横向溢出、正文无小于14px、受检按钮高度不小于44px。报告：`test-results/assessment-ui-smoke/report.json`。
- 批量导入11个场景、4个布局通过；课程工作台9个流程、13个布局通过；账户会话竞态浏览器检查通过。测试使用隔离数据，不清空用户空间。
- 当前本地账户内使用已配置的真实模型，从示例高数资料生成并核对一题连续定义单选；查看来源后按辅助练习提交，未累计掌握度。原文定位、刷新后保留题目与反馈、主动回看反馈均成功；仅留1次辅助作答用于复核，没有重置账户或原有学习资料。

## 已知边界

Docling公式富化关闭，OCR和结构提取可能有误，复杂公式仍应对照原件。来源核验能验证引用确实存在，不能证明生成答案科学正确或数学等价。当前没有复制DeepTutor的通用工具执行系统，也没有实现计算机代数证明。旧资料若此前没保存原件，可重新导入；同文件选择增强模式会原位重新解析并清理依赖旧片段的练习。JSON学习导出不包含原件二进制，应另行保管原文件。
