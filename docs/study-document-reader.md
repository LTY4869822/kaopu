## 学生操作

- 桌面为资料与对话两个区域；顶部“资料”可收起，“产物”按需滑出成稿架，保持对话宽度。窄屏使用资料/对话/产物页签。
- 右侧只收纳讲义和练习卷，笔记正文不再挤在侧栏。点击“阅读讲义”或对话中的讲义卡片，打开独立文档阅读区。
- 阅读区展示真正的PDF，可搜索、缩放和下载。下载Word得到可编辑的DOCX，包含标题层级、正文、公式、表格、目录与来源索引。
- 修订笔记或据此练习会回到原有学习流程。返回或按Escape关闭文档，保留工作台状态。
- 网课精读新增“PDF / Word 阅读”；课程资料中的网课讲义也可打开相应讲次的文档。
- 生成后的重复保存状态已去掉，聊天不再同时显示大段“已保存”说明、成稿卡片和完成通知。

## 导出实现和运行条件

`server/study-document.mjs`采用Markdown结构解析、KaTeX、MIT开源Paged.js和本机Chromium生成PDF。目录页码取自实际分页目标，包含层级、点线、链接、页眉和页脚。Word使用独立OOXML、原生TOC/PAGEREF目录域、点线制表位；分式、上下标、根号、矩阵转换为可编辑Office Math。原始Markdown记录与既有API仍保留，便于修订和已有练习引用。

首次在新环境运行PDF前执行：

```powershell
npm install
npm run setup:pdf
```

可用`DOCUMENT_CHROMIUM_PATH`指定已有Chromium可执行文件；当前Windows机器已找到本机浏览器。部署Linux时需准备能显示中文的系统字体。基础Word导出不需要浏览器或Office；当前Windows如检测到Office16，会在独立隐藏Word实例内更新目录缓存，最多同时一个且限时45秒，只处理临时合成文件，不接管用户已打开的Word实例。`DOCUMENT_WORD_PAGINATION=off`可关闭此可选步骤。没有Word或更新失败时仍返回带原生目录域的DOCX；用Word打开后更新目录，页码以该软件实际排版为准，不套用PDF页码。其他阅读软件可能略有字体和排版差异。

渲染浏览器禁止外网与本机网络请求，用CSP禁止文档自身执行脚本；仅通过浏览器控制端执行项目安装的Paged.js分页代码。正文HTML已转义，模型生成的远程图片不加载。文档接口沿用本机账户保护，不把私有笔记放入公共静态目录。

同时最多准备两份文档，并对相同内容请求合并；缓存仅存在进程内、按内容区分版本并有数量/体积上限。笔记来源变化时历史稿明确标记。网课新画面尚未合入讲义时禁止把旧讲义导出为新文档；异步生成完成后再次检查讲次版本。

网课PDF/Word保留主讲义、补充讲解、例题及可用原图，不自动附上整课逐字转写；原始转写仍可在原文页及原有图文HTML导出中查看。截图缺失会保留提示，不生成替代图片。

## 验证

- `tests/study-document.test.mjs`验证格式、中文可搜索、公式结构、完整OOXML包、目录/来源锚点、截图打包、旧Markdown兼容、登录保护与只读导出。
- `scripts/studio-document-ui-smoke.mjs`在隔离资料库验证资料收起、抽屉开合与焦点限制、去重提示、实际PDF预览及下载、Word下载、错误重试、返回修订、Escape焦点恢复，以及1100/390/320像素布局和正常/减少动态两种偏好。
- `scripts/study-document-check.mjs`生成合成线代讲义，PDF与DOCX均已逐页渲染检查中文、表格和数学公式。
- 标准`render_docx.py`因本机未安装LibreOffice无法运行。保留其诊断后，使用已安装的Microsoft Word以隐藏实例打开只读合成文件并导出PDF，再用Poppler渲染全部页面检查；未改动用户的Word文件。

相关测试与截图在`test-results/study-document/`和`test-results/studio-document-ui/`。它们是隔离验收样例，不代表对用户全部生成笔记进行了学科正确性审查。

笔记生成规则已增加资料支持的定义、适用条件、推导、例题、易错点与回忆自测结构。旧稿重新导出只改变排版；需要通过修订或重新整理丰富内容。`scripts/study-note-live-check.mjs --live`会显式调用已有配置的模型，用合成线代材料在临时资料库走完生成、保存和双格式导出，不改用户课程。
