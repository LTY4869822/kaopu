# 独立演示组件规格

仅编辑src/LandingDemos.tsx、src/landing-demos.css。父组件负责叙事、导航、滚动与认证，演示不能调用API或写入学习数据。

导出StudyDemo({step}:{step:0|1|2})与LectureDemo()。样式全部使用lp-demo-/lp-lecture-前缀，或.landing-page后代；不重置body、全局button或h标签。导入自己的CSS。

视觉：暖白#f5f3ec、近黑#1b1c19、橙#f45b35、浅橄榄#e8eadf。精致清晰的学习产品预览，18px左右面板标题，12–15px元数据，边框细线，10px以内圆角，纸张轻阴影。父页面桌面演示宽约580px，高450px；手机宽342px，自适应不可横溢。只用现有React/Phosphor，不新增依赖。

StudyDemo是同一固定高度小工作台，不是三个营销卡片。顶部细栏带“考谱 / 学习空间”和“交互演示”；左侧窄目录，高数/线代/英语。右侧随step变化：

- step0资料归档：高等数学，3份资料；显示“第二章 导数.pdf”“课堂例题.pptx”“期末范围.docx”与不同文件图标、页数。点击任一显示该示例的知识点短文，例如“左右导数存在且相等 ⇔ 可导”。保留“示例资料”标识。
- step1复习计划：标题“今天，先做好这三件事”，一周日期行，3项任务“复习导数定义 20分钟”“做一道分段函数题 15分钟”“回顾昨天的记忆卡 10分钟”。每项checkbox可选/取消，总完成N/3跟随变化，必须标明“示例计划”。
- step2练习记忆：标题“看懂了，再试一次”，一张题卡“左右导数都存在，函数就一定可导吗？”，按钮“翻看答案”，翻面显示“不一定。左右导数还必须相等。”，可再看题目。显示示例，不要虚假保存成功。

LectureDemo放在深色外部section，自己为白色／浅白工作台。顶部“网课精读 / 单侧导数”与“内容演示”标签。左右对照：左侧小深黑板，用独立HTML/公式模拟板书（标“板书示意”，不伪造真实课截图）；下有可点00:00导数定义、02:31单侧导数、04:23绝对值例题。点击改变选中、高亮右侧对应来源段，并显示选中时间。右侧提供原生button tabs“讲义”“例题”“板书”，切换确实显示不同内容，role语义/aria选中要正确。讲义含可导条件与短例；例题含y=|x|的左右导数并可展开解法；板书显示清晰公式与“抽样画面需核对原图”短句。公式可用LessonText渲染或HTML排版，不能一大串未渲染LaTeX。

所有按钮min40px，focus-visible明显，隐藏区不聚焦；prefers-reduced-motion时停用翻转／大位移，不隐藏内容。纯交互演示刷新可重置，不localStorage。

检查tsc通过。不要编辑AuthPage、AuthGate、LandingPage及全局CSS。不要用其他浏览器工具，可让父代理统一CUA检查。
