# 练习答疑流程与组卷排版优化

## Context

用户需要弄清专项练习与“理解应用”的题目依据，以及“模型题目校验未通过”的含义；同时希望解决自定义组卷页左右列长短不一、练习答疑入口与按钮层级混乱的问题。目标是让用户始终知道当前处于哪一步、下一步该做什么，并删除真正的重复入口，不改动现有出题、作答、讲评和资料答疑能力。

已核实：普通专项题不是从固定成品题库抽取。`server/assessment.mjs` 从所选课程已解析资料的 `documents.chunks` 选取原文证据，模型先生成出题蓝图再生成题目；“理解应用”的场景、选项、答案和解析由模型生成，来源引文必须匹配课程原文。“只练错题”复用历史错题。`MODEL_VALIDATION` 表示模型输出的结构、字段、答案或来源未通过契约校验；系统自动修复一次仍失败则整批不保存，旧练习和答案不受影响，并非用户答错。

## 实施方案

### 1. 明确专项练习的三步流程与题目来源

修改 `src/PracticeStudio.tsx` 与 `src/practice-batch.css`：

- 在专项练习内容区增加轻量、不可点击的步骤提示：**1 设置练习 → 2 完成作答 → 3 查看讲评**。根据现有 `set.status` 和提交状态推导当前步骤，使用 `aria-current="step"`，不新增业务状态或第二套导航。
- 在设置区用简短说明或可展开帮助说明普通模式与只练错题的来源差异；明确“理解应用依据当前课程已解析资料生成，可在讲评中核对原文”，不宣称它直接读取独立考点库或全部课程笔记。
- 保留现有课程切换、原文回忆/理解应用、题量、题型、练习重点和只练错题。生成、作答、提交、自动保存、来源核对和记忆卡逻辑不变。
- 生成成功后沿用现有状态安装与题号导航，通过步骤状态和清晰的设置摘要提示下一步；讲评仍保留逐题展开、查看来源和加入回忆复习。

### 2. 将模型校验失败改成可理解、可行动的提示

修改 `src/PracticeStudio.tsx` 与 `src/practice-batch.css`：

- 识别“模型题目校验未通过”错误，将其展示为“这次题目没有生成成功”，保留服务端提供的具体原因，例如“题目批次结构无效”。
- 补充说明：模型内容未通过格式或来源核对，自动修正后仍未通过；本次题目未保存，已有练习与作答不受影响。
- 错误区提供明确的下一步：保留现有开始按钮用于重新生成，并提示仍失败时减少题量、调整题型或练习重点。若增加“调整设置”动作，只负责展开并定位到现有设置区，不再创建第二套生成入口。
- 不修改后端校验规则、自动修复次数或入库逻辑，不用伪题静默降级。

### 3. 收敛练习答疑按钮与重复入口

修改 `src/App.tsx`、`src/PracticeStudio.tsx` 及必要样式：

- 删除练习答疑顶部的“整卷模拟”快捷入口，保留左侧主导航“期末模考”，避免同一页面重复跳转。
- 将“回忆复习”明确命名为“前往回忆复习”；它与讲评中的“加入回忆复习”功能不同，后者继续保留。
- 模型设置只保留练习区右上角一个入口；未连接模型时的内联提示改为文字指引，不再放第二个打开同一弹窗的按钮。
- 保留“专项练习 / 资料答疑”两个标签及共享课程筛选。资料答疑维持“选择课程并提问 → 查看讲解与来源”的独立流程，不混入专项练习三步，不新增重复提问按钮。
- 统一主按钮、次按钮和文字按钮的层级、间距及移动端换行，确保当前主行动只有一个。

### 4. 修复自定义组卷页左右列失衡

修改 `src/exam-studio.css` 与 `src/study-flow.css`，不调整 `ExamStudio.tsx` 的组卷业务逻辑：

- 统一基础样式与 quiet 覆盖样式的断点：宽屏保留“左侧范围与卷面结构、右侧卷面汇总与生成”双列；较窄桌面及移动端改为按操作顺序排列的单列，消除 901–1100px 强制双列造成的大片留白和阅读跳动。
- 单列顺序为“确定范围 → 安排卷面结构 → 卷面汇总与生成”；取消窄屏右侧吸附，汇总区在窄屏采用紧凑响应式布局，生成按钮清楚作为最后一步。
- 宽屏仅在视口高度足够时启用 summary sticky，低高度窗口保持静态；不强制两列等高。
- 恢复必要的步骤编号、关键设置说明和题型汇总，避免 quiet 样式把帮助信息全部隐藏；控制正文宽度、间距与长文本换行，兼顾模板组卷和自定义组卷。

## 验证

- 运行 TypeScript 检查、生产构建和现有全量测试。
- 运行并视需要扩展 `scripts/practice-batch-ui-smoke.mjs`：覆盖设置→作答→讲评状态、资料答疑独立流程、模型入口唯一、回忆复习两个不同功能、生成失败原因与重试提示、旧答案保留。
- 运行并视需要扩展 `scripts/exam-ui-smoke.mjs`：检查 1440、1199、1120、1100、900、390px 及低高度桌面，确认单双列顺序、sticky、汇总和生成按钮可见、无横向溢出。
- 浏览器实际复现三张截图对应状态，确认题目来源说明、错误提示、按钮层级、来源展开和移动端操作均正常。
