# 完整备份恢复实施计划

## Context

当前 `GET /api/export` 只导出 `state.json`，遗漏账户、模型配置、网课、资料原件和课程关键帧，无法用于灾难恢复。本次新增独立的全量备份与恢复能力，保留原JSON导出行为；备份包含账户哈希和模型API密钥，ZIP不加密，界面必须明确敏感提示。恢复采用“上传校验并暂存、重启后生效”，不做运行中热重载。

## 实施方案

### 1. 新增版本化备份模块

新增 `server/backup.mjs`，集中实现备份清单、数据遍历、ZIP校验、暂存恢复和启动切换。

* ZIP结构：`manifest.json` + `payload/<数据相对路径>`。

* 清单包含 `format: shifen-full-backup`、`formatVersion: 1`、创建时间、敏感数据标记，以及每个文件的路径、字节数和SHA256。

* 权威数据范围：`state.json`、`lessons.json`、`auth.json`、`model-service.json`、`documents/*.bin`、`lesson-visual/**/manifest.json`和`frame-*.jpg`。

* 排除会话、账户恢复令牌、重置前快照、临时文件；拒绝符号链接、junction、路径逃逸及未登记的数据文件，避免静默生成不完整备份。

* 备份时取得操作锁并阻止新写请求，对文件集合和哈希做两次一致性检查；数据仍变化则返回409，稳定后从同一快照生成ZIP。

* 设置首版边界：压缩包最大256 MiB、总解压大小最大512 MiB、条目数及单文件大小受限，超限明确失败，不省略文件后仍宣称完整。

### 2. 安全校验与暂存恢复

新增路由：

* `GET /api/backup`：登录后下载完整ZIP。

* `POST /api/backup/restore`：登录后通过FormData上传一个ZIP，成功后返回202和`restartRequired: true`。

* `GET /api/backup/status`：仅公开维护状态，不暴露账户、文件路径或备份内容。

恢复流程：

1. 校验ZIP格式、版本、清单、文件集合、重复/冲突路径、大小和SHA256；解析必要JSON，并检查资料原件与视觉证据引用。
2. 在`dataDir`同级创建随机恢复工作目录，逐项安全写入；任何失败都清理工作目录且不改正式数据。
3. 校验通过后原子发布为唯一的`restore-pending`；已有待恢复任务时返回409。
4. 当前进程进入不可解除的`restart-required`维护状态，除状态查询外的API返回503和`RESTART_REQUIRED`，并触发已有`shifen:close`取消后台任务。
5. 下次`createApp`时，在读取任何业务状态前，将旧目录改名为回滚副本、待恢复目录切换为正式目录；应用初始化成功后清理暂存和回滚，任一步失败则恢复旧目录并抛出错误。识别并回滚启动切换中断的目录状态，避免生成新的示例空间。

保留现有`/api/export`及其测试语义，完整备份只走新接口。

### 3. 主服务接线

修改 `server/index.mjs`：

* 将现有应用构建保留为内部函数，新增轻量`createApp`包装，在正常初始化前后执行待恢复切换、提交或回滚。

* 复用现有认证、Origin写保护、安全响应头和统一错误处理。

* 在认证前注册无敏感信息的备份状态路由与维护闸门；备份下载和恢复路由安装在认证守卫之后。

* 恢复上传使用独立Multer限制和错误文案，不复用20 MB资料上传提示。

### 4. 设置页与重启阻断界面

修改 `src/AppSettings.tsx`、`src/api.ts`、`src/AuthGate.tsx`及现有设置样式：

* “账户与数据”新增“完整备份与恢复”，保留原“导出学习数据”入口。

* 说明备份包含课程、学习记录、原始资料、网课资源、账户密码哈希和模型API密钥，ZIP未加密，只能恢复到可信环境。

* 下载使用Blob/ObjectURL，显示执行中和错误状态。

* 恢复要求选择ZIP并勾选覆盖确认，上传期间禁止重复提交；失败保留当前页面并展示可操作错误。

* 恢复成功或后续API收到`RESTART_REQUIRED`时显示整页阻断提示，说明数据尚未替换、需重启服务后刷新，并使用备份账户重新登录。

* 首次加载先检查维护状态，避免旧进程继续展示陈旧学习数据。

### 5. 自动化覆盖

新增 `tests/backup.test.mjs`：

* 全量文件与清单哈希、临时文件排除、未知文件和符号链接拒绝。

* 非ZIP、损坏ZIP、版本不符、路径穿越、重复路径、额外/缺失文件、大小或哈希不符、超限上传。

* 备份期间数据变化与并发操作返回409，失败后正式数据不变。

* A空间导出、B空间暂存、维护状态、重启后完整往返，覆盖课程、私密模考内容、练习、复习、网课、原件、关键帧、账户和模型配置。

* 认证/Origin保护、第二次重启不重复恢复、初始化失败与目录切换失败回滚。

新增或扩展UI smoke，覆盖ZIP下载、敏感提示、恢复确认、上传错误、重启阻断和320/390px布局；更新设置导航测试中的新增控件断言。

## 关键文件

* 新增：`server/backup.mjs`、`tests/backup.test.mjs`、必要的备份UI smoke脚本。

* 修改：`server/index.mjs`、`src/AppSettings.tsx`、`src/api.ts`、`src/AuthGate.tsx`、`src/app-settings.css`、`scripts/settings-navigation-smoke.mjs`。

* 复用：`scripts/package-handover.mjs`的SHA256和路径检查思路、`auth.mjs`的登录守卫、现有`shifen:close`任务清理，以及`api.test.mjs`的临时目录和随机端口模式。

## 验证

1. 运行新增备份测试及受影响的认证、API、模考、网课测试。
2. 运行备份恢复UI smoke和设置导航UI测试。
3. 运行`npm test`，确认全部Node测试通过。
4. 运行`npm run build`，确认TypeScript和生产构建通过。
5. 手动核对恢复失败不修改正式数据、待恢复状态刷新后仍阻断、重启后数据完整且旧登录会话失效。
